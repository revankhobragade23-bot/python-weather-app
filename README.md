# Python Weather App 🌦️

A simple Python project that uses the OpenWeatherMap API to fetch real-time weather information for a city.

## Features

- Search weather by city name
- Displays temperature
- Displays feels-like temperature
- Shows weather condition
- Shows humidity
- Shows wind speed
- Handles invalid API requests

## Technologies Used

- Python
- Requests
- OpenWeatherMap API
